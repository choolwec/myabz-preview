# MyABZ — enhancement preview

A clickable preview of the redesigned MyABZ online banking interface, for internal
review by the AB Bank Zambia team.

**Everything here runs on sample data.** No real accounts, balances or customers.

- `app/` — the interface, built from the production React codebase and running on mock data
- `branding/` — the version built by AB Bank's brand and marketing team, kept for reference

The separate clickable prototype was retired in September 2026. It was a second
hand-maintained copy of the same screens, and `app/` is the one the bank's developer
inherits.

Source, research and backend handoff live in the private `abz-ob-frontend` repository.
